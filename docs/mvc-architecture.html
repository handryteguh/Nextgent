MVC-style Architecture — Next.js Mina-UI

Pola PHP MVC (CodeIgniter/Laravel) → dipetakan ke struktur Next.js App Router. Prinsip sama: Controller tipis, Model pegang logika, View cuma render.
FRAMEWORK v0.3
📁 Route Handler = Controller
  • Export GET/POST di app/api/*
  • Terima request, validasi, panggil service
  • Harus TIPIS — gak ada logika berat
🧠 Service = Model
  • Logika bisnis: verifikasi PIN, lockout, FU
  • Hanya service yang sentuh database
  • Gampang di-test sendirian
🎨 Komponen = View
  • React components + page.tsx
  • Cuma render data — gak kenal DB
  • Reusable: Button, Card, DataTable
🛡️ Middleware = Gate
  • Kaya filter auth di CodeIgniter
  • Cek session/PIN sebelum render
  • Redirect ke /login kalau belum masuk
