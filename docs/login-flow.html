SECURITY v1
🔢 Percobaan Login
  • Maksimal 5x salah password per sesi
  • Sisa percobaan ditampilkan ke user
  • Benar di percobaan mana pun → langsung masuk
🔒 Lockout / Cooldown
  • Setelah 5x gagal → login dikunci sementara
  • Default 5 menit (bisa dikonfigurasi)
  • Hitung mundur ditampilkan ke user
🔄 Reset
  • Setelah cooldown selesai → counter reset ke 0
  • User bisa coba login lagi dari awal
  • Login sukses juga me-reset counter
